# Design reference

`reference.html`은 이 사이트의 디자인 프로토타입 원본이다.

원본은 22MB짜리 자체 포함 번들(폰트가 base64로 인라인)이라 그대로 읽기 어려워서,
번들에서 마크업과 로직만 추출해 보관한다.

- `<x-dc>` 블록 = 7개 화면의 마크업 (인라인 스타일)
- 하단 `class Component extends DCLogic` = 화면 전환 상태와 더미 데이터

구현 시 간격 · 보더 · 폰트 크기를 이 파일과 대조한다.
브라우저로 직접 열면 렌더링되지 않는다 (런타임과 폰트가 빠져 있음). 소스로만 참고할 것.
